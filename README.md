# 📊 SQL Exploratory Data Analysis (EDA) - Layoffs Dataset

## 📌 Project Overview

This project explores a real-world layoffs dataset using SQL to uncover meaningful business insights. The analysis focuses on identifying trends, comparing layoffs across companies, industries, countries, funding stages, and years, while also examining monthly layoff patterns.

The project demonstrates how SQL can be used to answer business questions and support data-driven decision-making.

## 📂 Dataset

- Layoffs Dataset

## 🎯 Business Questions

- Which company had the highest number of layoffs?
- Which industries were most affected?
- Which countries experienced the highest layoffs?
- Which year recorded the highest layoffs?
- Which funding stages were impacted the most?
- How did layoffs change over time?
- Which companies had the highest layoffs each year?
- What is the cumulative trend of layoffs over time?
